为什么是文字

画布的全状态，就是一段可编辑的文字。

不是导出一份文件，是画布本身就有文字形态。所以 AI 能直接驱动它、改动可 diff、跨设备可迁移、应用前可确认。

真实界面

不是概念图，是能跑的产品。

自研 Canvas 2D 引擎驱动画布；本地优先，数据默认留在你的机器。v1.4 起，界面按 Swiss Editorial 设计语言重绘；当前 v1.5.0。

它能做什么

一张画布，长出你的知识。

核心不是功能堆叠，而是一条可恢复的工作流：捕获 → 待整理 → 画布 → 找回 → 继续编辑。

01

捕获到找回

快速捕获先保住想法，Inbox 再决定目标画布；画布搜索命中后回到原位置，工作台继续编辑。

02

DSL 安全编辑

画布可以转成可读文本。修改先解析、预演并显示元素差异；确认后才应用，过期 revision 会被拒绝。v8 起卡片带结构化字段（标签 / 外链 / 代码块 / 引文）双向往返。

03

AI 可选，不越界

支持 OpenAI、Anthropic 与本地 Ollama。AI 提案走确认门和 stale guard，未配置时核心功能照常使用。

04

自研画布引擎

不依赖第三方画布库，2D Canvas 自研引擎 —— 轻量、可控、可剥离。几何 / 渲染 / 交互各司其职，六种元素自由组合。

05

可恢复的数据

JSON 导入先 dry-run，再选择 replace / merge；写入前创建本机恢复点，跨 store 失败会回滚。

06

Markdown 工作台

Source / Split / Preview 三态继续编辑。标题、列表和正文换行正确渲染，卡片预览不再暴露 Markdown 语法。

隐私是默认，不是选项。

本地优先不是营销词，是架构选择。你的想法先落在自己的磁盘上，是否导出由你决定。

在 GitHub 读源码 ↗
  • 存储 当前 Web / Tauri 前端使用 localStorage + OPFS，默认无应用服务器。
  • 无遥测 不内置任何遥测 / 崩溃上报 / 行为统计；数据不经云端，网络请求只发生在你配置 AI 时。
  • AI 隐私 字段白名单：设备标识、媒体二进制、软删除卡片不进提示词。
  • 本地 AI 可接 Ollama 纯本地模型，断网也能用。
  • 恢复 导出的 JSON 会自动脱敏；导入前恢复点只留在本机。
